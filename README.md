# Development template

Copy the contents of this directory into the root of a new or existing project,
then replace the placeholders in `AGENTS.md` with the project's canonical
commands and conventions.

```text
.
|-- AGENTS.md
|-- spec/
|   `-- TEMPLATE.md
|-- docs/
|   `-- adr/
|       `-- TEMPLATE.md
`-- skills/
    `-- README.md
```

The root policy file explains when specifications, ADRs, and skills are needed.
The templates hold their detailed document structure so `AGENTS.md` remains
focused on actionable repository rules.
